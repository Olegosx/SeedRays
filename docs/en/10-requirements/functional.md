# Functional Requirements

What the system does. Content to be extended.

## Primary Mode of Operation

The gateway's primary mode is the persistent binding of payment addresses to accounts of
connected applications: a connected application requests a permanent payment address for
each of its users, and the application owner reads the state of the user's internal balance
through the operations observed on that address. Single invoices are planned for a later
stage.
See [ADR-0009](../20-architecture/decisions/0009-address-bindings-primary-mode.md).
