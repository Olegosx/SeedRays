# Модуль деривации

Выводит платёжные адреса из расширенного публичного ключа (xpub) по стандарту HD-кошельков
(BIP32).

## Назначение

- Работает в онлайн-части в наблюдающем режиме (watch-only): для деривации адресов приватный
  ключ не нужен, поэтому компрометация сервера не раскрывает средства.
  См. [ADR-0002](../decisions/0002-watch-only-online-part.md).
- Доступен и как модуль (его вызывает [оркестратор](orchestrator.md) для выдачи платёжных
  адресов), и как самостоятельная консольная команда
  (см. [ADR-0001](../decisions/0001-library-first-core.md)).
