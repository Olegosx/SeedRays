# Абстракция блокчейна

Интерфейс «источник данных цепочки», отделяющий [watcher](watcher.md) и остальной бэкенд от
конкретного способа доступа к блокчейну.

## Назначение

- Первые реализации работают через публичные API провайдеров; последующий переход на свою
  развёрнутую ноду (RPC) не должен затрагивать логику компонентов над абстракцией.
- На каждую цепочку — своя реализация в `chains/` (например, `tron/`).

## Поддерживаемые цепочки

Сначала TRON; далее ETH, TON и другие. Детали будут определены.
