# Watcher

Наблюдает за балансами и входящими платежами по кошелькам всех пользователей.

## Устройство

Построен по принципу «library-first» (см. [ADR-0001](../decisions/0001-library-first-core.md)):

- **Один проход** — базовая операция: опросить источник данных по отслеживаемым адресам,
  зафиксировать новые поступления и изменения балансов.
- **Постоянный режим** — цикл, вызывающий «один проход» с заданным интервалом; работает
  фоновым потоком/задачей, которую запускает и контролирует [оркестратор](orchestrator.md)
  (см. [ADR-0003](../decisions/0003-single-process-supervised.md)).
- **Консольная команда** — разовая проверка для отладки и ручного контроля, использующая тот
  же код «одного прохода».

## Многопользовательский проход

Watcher мыслит адресами, а не пользователями
(см. [ADR-0007](../decisions/0007-address-centric-watcher.md)):

- Перед проходом он собирает со всех пользователей единый рабочий список отслеживаемых
  адресов; каждый адрес помечен владельцем (пользователь, кошелёк) и цепочкой.
- Проход обрабатывает список с группировкой по цепочке и провайдеру данных: лимиты запросов
  у провайдера общие на весь шлюз, поэтому частота запросов управляется централизованно,
  а там, где провайдер умеет пакетные запросы, используются они.
- Справедливый порядок: пользователь с множеством адресов не должен вытеснять пользователей
  с малым числом адресов.
- Ошибки изолируются на уровне адреса/пользователя внутри прохода: записываются в журнал и
  не прерывают проход для остальных.
- Результаты раскладываются по базам владельцев через [слой хранения](storage.md).

## Доступ к данным

Весь доступ к блокчейну идёт через [абстракцию блокчейна](chain-abstraction.md): сначала
публичные API провайдеров, позже — своя развёрнутая нода (RPC) — без изменений в логике
watcher.

Служебное состояние watcher — высота последнего обработанного блока по каждой сети —
хранится в общей реестровой базе: это одновременно точка возобновления сканирования после
остановки и высота, от которой вычисляется количество подтверждений
(см. [ADR-0010](../decisions/0010-networks-assets-financial-data.md)).
