# ADR-0019: Локализация фронтенда — клиентские словари

**Статус:** принято

## Контекст

Интерфейс кабинета многоязычный: на старте — русский и английский, дальнейшие языки
должны добавляться без переделки страниц. Фронтенд — статика без сборки ([ADR-0012](0012-frontend-stack.md)),
общается с бэкендом только через HTTP API. Кабинет находится за входом и в принципе не
работает без JavaScript (Alpine.js, запросы к API) — значит, классические доводы за
серверную локализацию (доступность без JavaScript, индексация поисковиками) к нему
неприменимы.

## Решение

- **Одна вёрстка + словари переводов.** Все надписи страниц получают ключи; переводы лежат
  в словарях — обычных ES-модулях (`i18n/ru.js`, `i18n/en.js`), по файлу на язык.
- **Выбор языка**: сохранённый выбор пользователя → язык браузера → английский. Выбор
  хранится в localStorage; переключатель — на странице входа и в настройках профиля.
- **Механика**: модуль `js/i18n.js` выставляет атрибут `lang` страницы и заголовок вкладки
  (по атрибуту `data-title-key`) и отдаёт словарь Alpine как общее хранилище `$store.i18n`;
  надписи подставляются через `x-text` и привязки атрибутов; до инициализации Alpine
  страница скрыта правилом `x-cloak` — сырые ключи не мелькают.
- **Новый язык** — один новый файл словаря, вёрстка не меняется.

## Рассмотренные альтернативы

- **Серверный рендеринг страниц под язык (PHP или Python):** отклонено — либо размывает
  границу «фронт ↔ только HTTP API», либо добавляет второй постоянный сервис (а PHP — ещё
  и второй языковой стек с собственной поверхностью аудита); преимущества серверной
  локализации кабинету за входом не дают ничего.
- **Отдельные страницы на каждый язык** (как устроена документация): отклонено — каждая
  правка вёрстки умножается на число языков; при росте числа страниц версии неизбежно
  расходятся.
- **Пред-генерация языковых версий сборкой:** отклонено — возвращает сборочный конвейер,
  исключённый [ADR-0012](0012-frontend-stack.md).

## Последствия

- Дисциплина ключей: надписи в вёрстке не пишутся текстом, только ключами словаря.
- Оба словаря поставляются всем пользователям — на нашем масштабе это килобайты.
- Если появится публичная часть (лендинг, документация для разработчиков приложений), её
  локализация решается отдельно — там доводы за серверную или пред-генерацию реальны.
