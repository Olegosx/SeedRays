# ADR-0020: Отправка почты — сторонний сервис за абстракцией

**Статус:** принято

## Контекст

Кабинету нужны служебные письма: подтверждение почты при регистрации, восстановление
пароля. Свой почтовый сервер — отдельная эксплуатационная дисциплина (репутация домена,
попадание в спам), несоразмерная объёму в единицы писем. Целевая аудитория шлюза —
не российская. Тарифы сверены с сайтами сервисов (2026-09-03): Resend — 3000 писем/мес
бесплатно бессрочно (до 100/день); Postmark — бесплатно лишь 100 писем/мес; Unisender Go —
6000/мес бесплатно только первые два месяца, далее от 800 ₽/мес.

## Решение

- **Отправка писем — через сторонний сервис**; первый провайдер — **Resend**
  (`POST https://api.resend.com/emails`, ключ в заголовке Authorization) через httpx.
- **Абстракция «отправитель почты»** — тот же принцип, что источник данных цепочки
  ([ADR-0015](0015-tron-provider.md)): интерфейс с одной операцией «отправь письмо»;
  вызывающий код не знает, что за ним. Смена или добавление провайдера (включая обычный
  SMTP) — новая реализация, не переделка.
- **Реквизиты — настройки реестра** ([ADR-0016](0016-config-layers.md)): ключ API и адрес
  отправителя; управляются оператором, в коде и журналах не появляются.
- **Режим разработки**: пока реквизиты почты не заданы, регистрация подтверждает почту
  автоматически с предупреждением в журнале — шлюз работоспособен без внешнего сервиса.

## Рассмотренные альтернативы

- **Свой SMTP-сервер:** отклонено — репутация и доставляемость дороже, чем весь объём
  наших писем; остаётся возможной реализацией за абстракцией для закрытых инсталляций.
- **Postmark:** бесплатного уровня (100 писем/мес) мало; отклонено как старт.
- **Unisender Go:** сильный вариант для российской аудитории (рублёвая оплата, местная
  инфраструктура), но аудитория шлюза не российская; отклонено как старт.

## Последствия

- Письма подтверждения несут одноразовый токен; в базе хранится только его отпечаток
  SHA-256 со сроком действия.
- Доставка зависит от внешнего сервиса; его отказ не роняет регистрацию молча — ошибка
  отправки возвращается пользователю явно.
- Будущий блок настроек оператора получает поля реквизитов почты.
