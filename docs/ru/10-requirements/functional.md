# Функциональные требования

Что делает система. Содержание будет дополняться.

## Основной режим работы

Основной режим шлюза — постоянная привязка платёжных адресов к аккаунтам подключённых
приложений: подключённое приложение запрашивает постоянный платёжный адрес для каждого
своего пользователя, а владелец приложения получает состояние внутреннего баланса
пользователя через операции, наблюдаемые по этому адресу. Единичные инвойсы запланированы
на более поздний этап.
См. [ADR-0009](../20-architecture/decisions/0009-address-bindings-primary-mode.md).
