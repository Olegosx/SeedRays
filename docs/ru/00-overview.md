# Обзор

SeedRays — лёгкий платёжный шлюз для приёма криптовалютных платежей на HD-кошелёк.

## Кратко

- Основные компоненты: генератор ключа, модуль деривации, watcher (балансы, поступления) —
  их координирует оркестратор (сервисный слой бэкенда).
- Онлайн-часть — наблюдающая (watch-only): хранит только расширенный публичный ключ (xpub)
  и подписывать ничего не может.
- Многопользовательский: у каждого пользователя личный кабинет, один или несколько кошельков
  и собственные база данных и рабочая директория. Три роли доступа: оператор шлюза,
  пользователь, приложения пользователя.
- Основной режим: постоянная привязка платёжных адресов к аккаунтам подключённых
  приложений; единичные инвойсы — позже.
- Поддерживаемые цепочки: сначала TRON; далее ETH, TON и другие.
- Бэкенд: Python; источники данных блокчейна — за слоем абстракции; данные — в
  пользовательских базах плюс небольшой общий реестр, за слоем хранения (сначала SQLite,
  далее PostgreSQL и MySQL).
- Внешний интерфейс: небольшой HTTP API с тремя группами маршрутов — по одной на роль.
- Общая структура: бэкенд + фронтенд (статика без сборки, без Node.js).
