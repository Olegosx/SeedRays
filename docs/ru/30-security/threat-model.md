## Генерация ключа в шлюзе (принятые остаточные риски)

Когда пользователь выбирает генерацию в шлюзе
(см. [ADR-0002](../20-architecture/decisions/0002-watch-only-online-part.md)), существуют
следующие риски, которые пользователь принимает явно:

- В момент генерации секрет (сид-фраза, приватный ключ) существует в памяти бэкенда.
- Секрет передаётся по сети в браузер пользователя для однократного показа.

Обязательные меры со стороны реализации: только HTTPS (кука сессии помечена Secure);
секрет никогда не пишется в журналы, базу данных и сохраняемые ответы, и ни одна ссылка
на него не живёт дольше породившего запроса. Гарантированно затереть память для строк
Python технически недостижимо — остаточное окно до сборки мусора входит в принятый выше
риск. Гарантия «нигде не сохраняется» покрыта тестом: сгенерированная фраза встречается
только в одноразовом ответе — ни в базах, ни в журнале
(см. [Генератор ключа](../20-architecture/components/key-generator.md)).
